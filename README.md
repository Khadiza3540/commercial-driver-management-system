# 🚛 Commercial Driver Management System (CDMS)

An AI-powered Commercial Driver Management System designed to improve road safety through driver monitoring, face recognition, drowsiness detection, trip management, and real-time alert generation.

## 📌 Project Overview

The Commercial Driver Management System (CDMS) is a smart driver monitoring platform developed to help transportation companies manage drivers, monitor driving behavior, and reduce accident risks through AI-based technologies.

The system integrates facial recognition, driver authentication, drowsiness detection, trip tracking, alert management, and administrative monitoring into a single platform.
