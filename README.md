# 🚗 Commercial Driver Management System

An AI-powered system for monitoring commercial drivers with real-time drowsiness detection using Computer Vision.

## 🔥 Features
- Driver Information Management
- Real-time Camera Monitoring
- Drowsiness Detection (Eye tracking, fatigue analysis)
- Alert System (Alarm / Warning)
- Trip Management
- Reports & Analytics Dashboard

## 🧠 Technologies Used
- Python
- OpenCV
- TensorFlow / Deep Learning
- Dlib (Face Landmarks)
- Tkinter (UI)
